<h1>Practical Linux For Devops</h1>  

<h2>Description</h2>
This repository is the result of my hands-on practice with Linux, focused on real-world tasks needed in DevOps and system administration. I completed 18 labs that cover essential topics like system monitoring, file management, networking, and automation.


<h2>What I Practiced</h2>

- Shell commands and scripting  
- Remote access with SSH  
- File and directory management  
- Permissions and documentation  
- System boot and service control  
- Performance monitoring and logging  
- Filesystem setup and mounting  
- Package installation and updates  
- Network configuration and testing  
- User and group management  
- Compression and archiving  
- Cron job scheduling and time sync  
- Secure file transfers (scp, rsync)  
- Advanced file permissions (chmod, chown, ACLs)  
- Managing background services and daemons
